I am a final-year B.Tech student in **Artificial Intelligence & Data Science** at **Alard University, Pune**, with active industry experience as an **AI & Data Science Intern at MinaTech Labs**.

- 🚀 **Production Backends:** Architecting scalable microservices and backend systems using **Python, FastAPI, and PostgreSQL**, implementing Role-Based Access Control (RBAC), JWT authentication, and secure data handling for live platforms.
- 📱 **Mobile Development:** Engineered the mobile foundation for enterprise operations using **React Native and TypeScript**.
